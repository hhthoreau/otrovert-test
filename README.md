# 이향인(Otrovert) 성향 검사 웹 애플리케이션

도서 《이향인》에 수록된 40개 문항과 188점 기준 채점 방식을 기반으로 제작된 모던 심리 검사 웹 애플리케이션입니다.

---

## 🌟 주요 특징

- **파일 순서 기반 10단계 구성 (001.JPG ~ 010.JPG)**
  - 원본 검사지 10개 페이지 순서대로 4문항씩 배치하여 안정적인 몰입감 제공
- **7단계 리커트 척도 & 정밀 채점 엔진**
  - 문항별 정방향(7→1점) 및 역방향(1→7점) 배점을 자동 계산하여 40~280점 범위로 산출
- **188점 기준 이향인 판정**
  - 총점 188점 이상: **이향인(Otrovert)** 판정 및 특성 해설
  - 총점 188점 미만: **비이향인** 판정 및 대인관계 조언
- **4대 세부 성향 분석 (HTML5 Canvas 차트)**
  - 주체성 및 독립심 (Autonomy)
  - 탈동조 및 자유로운 사고 (Non-Conformity)
  - 내면 사색 및 고요 (Introspection)
  - 타인 시선 및 인정 독립 (Social Independence)
- **로컬 스토리지 자동 저장**
  - 설문 도중 브라우저를 닫거나 새로고침해도 응답 내용이 안전하게 유지
- **모던 반응형 & 다크/라이트 테마**
  - 모바일 터치 최적화, 다크/라이트 모드 지원, 결과 요약 복사 및 인쇄/PDF 저장 기능

## 🚀 실행 및 배포 방법

### 1. 로컬에서 실행
웹 브라우저에서 `index.html` 파일을 열거나 로컬 웹 서버를 실행합니다.

```bash
# Python 내장 서버 실행 예시
python3 -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

### 2. GitHub Pages 배포
GitHub 저장소의 `Settings > Pages > Branch: main / root`를 선택하여 저장하면 바로 온라인 서비스가 시작됩니다.
